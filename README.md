# เสียงทะลุโหมดสั่น (SoundPierce)

แอป Android ที่ทำให้ **LINE** และ **สายโทรเข้าปกติ** มีเสียงเรียกเข้า **เสมอ**
แม้เครื่องจะอยู่ในโหมดสั่น/เงียบ

## แนวคิดการทำงาน

โหมดสั่นปกติจะปิดเสียงสตรีม RING/NOTIFICATION แต่ไม่ปิดสตรีม **ALARM**
แอปนี้จึงใช้ 2 กลไก:

| กรณี | วิธีทำให้มีเสียง |
|------|------------------|
| **LINE (และแอปที่เลือก)** ส่งการแจ้งเตือน | ฟังผ่าน `NotificationListenerService` แล้วเล่นเสียงเรียกเข้าผ่านสตรีม **ALARM** (ดังทะลุโหมดสั่น) |
| **สายโทรเข้าปกติ** | ตรวจจับสถานะ `RINGING` ผ่าน `PhoneStateReceiver` แล้วบังคับ ringer เป็นปกติชั่วคราว เพื่อให้เสียงเรียกเข้าของเครื่องดัง แล้วคืนค่าเดิมเมื่อวางสาย |

## ดาวน์โหลด APK

APK ถูก build อัตโนมัติด้วย **GitHub Actions** ทุกครั้งที่ push

1. ไปที่แท็บ **Actions** ของ repo นี้บน GitHub
2. เลือก workflow run ล่าสุด (Build APK) ที่ผ่าน ✅
3. ดาวน์โหลด artifact ชื่อ **SoundPierce-debug-apk**
4. แตกไฟล์ zip จะได้ `app-debug.apk` แล้วติดตั้งลงมือถือ
   (ต้องเปิด "ติดตั้งจากแหล่งที่ไม่รู้จัก" / Install unknown apps)

> สามารถกด **Run workflow** ในแท็บ Actions เพื่อสั่ง build เองได้ (workflow_dispatch)

## การตั้งค่าครั้งแรก (สำคัญมาก)

เปิดแอปแล้วกดอนุญาตสิทธิ์ทั้ง 3 อย่าง:

1. **การเข้าถึงการแจ้งเตือน** — จำเป็นสำหรับให้ LINE ทำงาน
   (ในหน้า Settings ให้เปิดสวิตช์ให้แอป "เสียงทะลุโหมดสั่น")
2. **การเข้าถึง Do Not Disturb** — จำเป็นสำหรับบังคับเสียงสายเข้าขณะเปิดโหมดเงียบ
3. **สิทธิ์อ่านสถานะโทรศัพท์** — จำเป็นสำหรับตรวจจับสายเรียกเข้า

จากนั้นเลือกเปิด/ปิดได้ว่าจะให้ **LINE** และ/หรือ **สายโทรเข้า** มีเสียง
และเพิ่มแอปอื่นได้เองด้วยการใส่ชื่อแพ็กเกจ (เช่น `com.facebook.orca`)

## Build เองบนเครื่อง (ต้องมี Android SDK)

```bash
./gradlew assembleDebug
# ได้ไฟล์ที่ app/build/outputs/apk/debug/app-debug.apk
```

## หมายเหตุ / ข้อจำกัด

- แอปเปลี่ยน ringer mode ชั่วคราวเฉพาะช่วงมีสายเข้า แล้วคืนค่าเดิมทันทีที่รับสาย/วางสาย
- LINE ต้องส่ง notification จริง (อย่าปิดการแจ้งเตือนของ LINE ในระบบ)
- ผู้ผลิตบางรายมีการจัดการแบตเตอรี่ที่เข้มงวด แนะนำตั้งแอปนี้เป็น "ไม่จำกัดการใช้แบต / No restrictions"
